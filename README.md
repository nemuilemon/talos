# Talos

> The bronze automaton that patrolled and guarded the island of Crete.
> クレタ島を巡回して見張る青銅の自動人形（Automaton）。

A terminal UI (TUI) and CLI crypto market watcher using public market APIs, written in Rust.
Renders real-time tickers, candlesticks, and volume in the terminal, with price target alerts — requiring no API keys.

公開 API を使った暗号資産の相場 TUI / CLI ウォッチャー（Rust 製）。
API key 不要（公開データのみ）で、端末上に ticker・ローソク足・出来高を描画し、指定価格への到達通知を行う。
